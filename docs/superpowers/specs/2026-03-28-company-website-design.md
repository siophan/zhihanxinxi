# 上海知涵信息科技有限公司 官网设计文档

## 概述

为上海知涵信息科技有限公司打造品牌展示型官网，采用单页滚动站形式，纯静态实现（HTML/CSS/JS），视觉风格为现代活力（渐变色彩、动感设计）。

## 公司信息

- **公司名称**：上海知涵信息科技有限公司
- **核心业务**：软件开发/IT服务、AI 相关、企业 SaaS 产品
- **备案号**：沪ICP备19039082号-3
- **Logo/品牌色**：无现有素材，从零设计

## 技术方案

- **架构**：单页面滚动站（Single Page）
- **技术栈**：纯静态 HTML + CSS + JavaScript
- **文件结构**：
  - `index.html` — 主页面
  - `css/style.css` — 样式文件
  - `js/main.js` — 交互逻辑
  - `assets/` — 图标、图片等资源

## 视觉风格

- **主色**：蓝紫渐变（`#667eea` → `#764ba2`）
- **辅色**：白色背景（`#ffffff`），浅灰文字（`#666666`），深色标题（`#333333`）
- **字体**：Google Fonts Noto Sans SC + 系统字体栈回退
- **动效**：
  - 滚动进入时元素淡入上移（CSS transition + Intersection Observer）
  - 导航栏滚动后添加背景色和阴影
- **响应式断点**：768px（平板）/ 1024px（桌面）

## 页面板块结构（从上到下）

### 1. 导航栏（固定顶部）

- 左侧：公司文字 logo「知涵信息」
- 右侧：首页 / 关于我们 / 产品服务 / 案例展示 / 新闻动态 / 联系我们
- 点击锚点平滑滚动到对应板块
- 移动端：汉堡菜单，点击展开导航列表

### 2. Hero 区域

- 全屏高度，渐变背景
- 居中大标题：「以科技驱动创新，用智慧赋能未来」
- 副标题：「专注软件开发、AI 智能与企业 SaaS 解决方案」
- CTA 按钮「了解更多」→ 锚点跳转至"关于我们"

### 3. 关于我们

- 左文右图布局（移动端上下堆叠）
- 左侧：公司简介（2-3 段占位文字）
- 右侧：占位图片区域
- 下方：发展历程时间线，3-4 个里程碑节点（水平排列，移动端垂直）

### 4. 产品与服务

- 三列卡片布局（移动端单列）
- 每张卡片：图标 + 标题 + 简述
- 三大业务线：
  - 软件开发与IT服务
  - AI 智能解决方案
  - 企业 SaaS 平台

### 5. 案例展示

- 网格卡片布局（桌面 3 列，平板 2 列，移动 1 列）
- 每张卡片：封面色块/占位图 + 标题 + 简述
- 放置 6 个占位案例

### 6. 新闻动态

- 列表式布局
- 每条：日期标签 + 标题 + 摘要文字
- 放置 4 条占位新闻

### 7. 联系我们

- 两列布局（移动端上下堆叠）
- 左侧：公司地址、电话、邮箱（占位信息）
- 右侧：留言表单（姓名、电话、留言、提交按钮）
- 表单纯前端，提交按钮点击后显示"提交成功"提示，不实际发送

### 8. 页脚

- 居中布局
- 上方：快捷导航链接
- 下方：「© 2026 上海知涵信息科技有限公司 沪ICP备19039082号-3」

## 交互细节

- 导航栏：滚动超过 Hero 区域后变为半透明白底 + 阴影
- 各板块内容：滚动进入视口时淡入上移动画
- 锚点导航：平滑滚动，当前板块对应导航项高亮
- 返回顶部按钮：滚动一定距离后出现在右下角
- 表单：基本的前端验证（必填项提示）

## 不包含

- 后端服务或数据库
- CMS 内容管理
- 多语言支持
- 用户登录/注册
